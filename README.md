# 🎓 LearnLoop AI V2

A polished Streamlit learning assistant with Gemini-powered tutoring and quiz generation, a no-key demo mode, quiz scoring, revision planning, and progress export.

**Hackathon concept:** Alexa+-inspired simulated agent experience. This is **not** an official Alexa+ integration.

## Run
Windows: double-click `start_windows.bat`.
Mac/Linux: `sh start_mac_linux.sh`.

See [SETUP_GUIDE.md](SETUP_GUIDE.md) for complete instructions and API-key configuration.

## Features
- Interactive tutoring chat with recent conversation context (Gemini mode)
- Explanations and dynamic four-option quizzes (Gemini mode)
- Offline predefined lessons and quizzes (Demo mode)
- Revision priorities from quiz results
- Downloadable progress data
- Dark-themed dashboard and built-in demo script
